# Velour Scent
Tienda pública (React 18 + React Router 6, estructura estilo Create React App).

    npm install
    npm start

- Estilos globales: `src/index.css` (tema) y `src/App.css` (tienda).
- Datos de ejemplo: `src/utils/api.js` (reemplazar por tu API).
- Imágenes: agregá `image` a cada producto en `api.js` (fondo oscuro, frasco bien iluminado).
